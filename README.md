# Laya Clash · 火柴竞技场

实时 1v1 动作对战网页游戏：程序化火柴人、天赋自由装配、本地 AI 对手，也支持浏览器间 P2P 联机对战。
零依赖、零构建、纯静态，支持手机 / 平板 / 桌面，离线可玩（联机需联网）。

## 玩法

- **三档对手**：新手挑战者 / 老手斗士 / 宗师魔王，AI 会轮换猛攻、铁壁、灵动、均衡四种天赋流派
- **天赋 DIY**：15 点数分入攻击 / 生存 / 机动 / 能量四系 + 2 个关键大点，局前随时改，打不过就换 build
- **操作深度**：三段连招、完美格挡弹反、破防硬直、冲刺无敌帧、跳跃滞空躲地面招、收招取消
- **技能池 6 选 2**：疾风(输出) / 干扰(控场) / 破空(对空) / 壁垒(防御) / 吸噬(续航) / 影袭(位移)，天赋页装配到 Q/E，对手 AI 按流派携带技能
- **P2P 联机**：浏览器直连（WebRTC），免服务器免账号，与好友互发两段房间码即可开打

## 操作

| 动作 | 键盘 | 触屏 |
|------|------|------|
| 移动 | A / D 或方向键 | 左半屏拖动摇杆 |
| 跳跃（躲地面攻击·耗 15 能量） | W 或 ↑ | 跳 |
| 轻击 | J 或鼠标左键 | 拳 |
| 重击 | K | 重 |
| 格挡（轻按弹反） | L | 防 |
| 冲刺 | Space | 冲 |
| 技能槽一 / 二 | Q / E | 对应技能按钮 |
| 暂停 | Esc 或 P | 右上 II |

## 联机对战

菜单进入「联机对战」，双方经聊天工具互传两段码（无需同一网络，无需服务器）：

1. **房主**：点「生成房间码」，把整段码发给好友
2. **访客**：粘贴房间码 → 点「生成应答码」，把整段码发回房主
3. **房主**：粘贴应答码 →「完成连接」→ 双方状态变绿后点「开始对战」

战斗判定在房主侧运行（主机权威），访客出招实时送过去；断线即回大厅，胜负与连击各记各的账。再战、退出对局、暂停均双向同步。

## 本地运行

ES Modules 需要 HTTP 环境，任选其一：

```bash
# Python
python -m http.server 8090
# 或 Node
npx serve .
```

打开 http://localhost:8090

## 部署到 Netlify

**方式一（拖拽）**：把本目录整个拖进 https://app.netlify.com/drop 即可。

**方式二（Git）**：推到 GitHub 后在 Netlify Connect 仓库，Build command 留空，Publish directory 填 `.`。

无需任何构建步骤与环境变量；游戏数据（天赋 / 战绩 / 设置）全部保存在玩家浏览器 localStorage。

## 技术

- 原生 ES Modules + Canvas 2D，无框架无打包
- 音效与配乐由 WebAudio 现场合成，无音频资源文件
- 角色动画为程序化骨架（状态驱动位姿插值），无图片素材
- 逻辑分辨率 1280×720，信箱式缩放适配任意视口，横屏提示
- 联机为 WebRTC DataChannel 手动 offer/answer（房间码互传），房主权威状态同步，访客只渲染不模拟
